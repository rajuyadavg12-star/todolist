# To-Do List

A modern, responsive To-Do List web app built with React, Vite, TypeScript, and Tailwind CSS.

## Features

- Add, edit, and delete tasks (with delete confirmation)
- Mark tasks as completed/uncompleted
- Filter by All / Active / Completed
- Search tasks by title
- Priority levels: Low, Medium, High
- Optional due dates with overdue highlighting
- Task statistics (Total, Active, Completed) with a progress bar
- Dark/light mode toggle (remembers your preference)
- Tasks persisted in `localStorage`
- Fully responsive with smooth animations and hover effects

## Getting started

```bash
npm install
npm run dev
```

Then open http://localhost:5173.

## Scripts

```bash
npm run dev      # start dev server
npm run build    # type-check + production build
npm run preview  # serve production build
npm run lint     # run oxlint
```

## Tech stack

- React 19 + TypeScript
- Vite 8
- Tailwind CSS 4
